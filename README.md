# Путь пакета

Учебный сайт-курс «Как работает сеть» для дисциплины «Веб-технологии»: 10 модулей, 28 уроков со схемами, практикой, проверкой, словарём и итоговым экзаменом. Сквозной пример — заказ такси в приложении.

Весь сайт — один файл `index.html` (HTML, CSS и JS внутри, без сборки). Откройте его в браузере или выложите на GitHub Pages. Прогресс хранится в `localStorage` браузера. Сайт рассчитан на десктоп.

Режим преподавателя: ссылка внизу карты курса или адрес с `#teacher`.
